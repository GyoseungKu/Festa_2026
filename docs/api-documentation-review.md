# API·마크다운 검토 기록

검토 기준일: 2026-09-14. 저장소의 API 컨트롤러, 요청·응답 DTO, 서비스 검증, 인증 필터, 파일 저장소와 기본 설정을 마크다운 문서와 대조했습니다. 운영 서버·외부 SSO의 현재 설정을 실측한 기록은 아닙니다.

## 범위와 검증

- 기존 루트 `README.md`, `HELP.md`와 `docs/`의 마크다운 전체를 읽고 기능별 문서를 대조했습니다. 디자인·UI 점검 문서도 현재 파일 구조 및 기록 시점과 비교했습니다.
- `HELP.md`는 기존 Git 제외 대상이므로 로컬 파일만 갱신했습니다. 공유할 개발 안내와 변경 내용은 추적되는 README·문서 목차에도 연결했습니다.
- 테스트 애플리케이션 OpenAPI 기준 98개 경로, 메서드 기준 125개를 [API 색인](api-endpoint-index.md)에 정리했습니다. `/api/**` 122개, 학교 콜백 1개, 관리자 JSON 조회 2개입니다.
- OpenAPI에 포함되지 않는 HTML 폼까지 확인하여 [관리자 웹 경로](admin-web-api.md)에 관리자 매핑 74개를 정리했습니다. 여기에는 위 JSON 조회 2개도 포함되므로 두 수를 단순 합산하지 않습니다.
- 기존 `OpenApiDocumentationIntegrationTests`를 H2 테스트 설정에서 실행해 통과했습니다. 추출 파일은 `build/reports/openapi.json`입니다.
- 문서의 상대 파일 링크, JSON 코드 블록, 코드 펜스와 색인의 메서드·경로를 검사했습니다. 문서 수정에 대한 검사이며 전체 기능 테스트·실제 SSO·R2·MySQL 통합 동작이나 브라우저 UI 검증을 새로 수행한 것은 아닙니다.

## 코드 보완이 필요한 현재 제약

문서 수정으로 해결되지 않는 항목입니다. 이번 작업에서는 API 동작을 변경하지 않았습니다.

1. **축제 탈퇴 익명화 대상 누락:** [FestivalWithdrawalService](../src/main/java/org/syu_likelion/Festa_2026/user/FestivalWithdrawalService.java)는 일반 공지의 작성자 이름·작성자/수정자 UUID와 협찬사의 생성자/수정자 UUID를 변경하지 않습니다. 새 기록 테이블 추가 시 삭제 범위도 함께 관리해야 합니다.
2. **SSO 탈퇴와 축제 기록은 별개:** 정상 프로필 조회에서 사용자가 없으면 `알 수 없음`으로 보정하지만 저장된 닉네임·게시글 스냅샷·학교 승인 요청을 삭제하는 작업은 아닙니다. 프런트 전체에서 모든 기록이 자동 익명화된다고 안내할 수 없습니다.
3. **학교 승인 요청의 수명·재검증:** 현재 자동 만료가 없고 승인 직전 계정 상태를 재검증하지 않습니다. 상세 제약과 기존 테스트 범위는 [학생 인증 문서](student-verification.md)를 따릅니다.
4. **SSO와 로컬 DB의 부분 성공:** 가입·학과 변경 등은 분산 트랜잭션이 아닙니다. SSO 처리 후 로컬 저장 실패를 무조건 같은 요청 재전송으로 복구한다고 안내하지 않습니다.
5. **채팅 단일 인스턴스·인증 캐시:** 변경 커서와 일부 제한은 현재 구현의 단일 인스턴스 전제가 있고, 인증 캐시는 기본 60초입니다. [채팅 운영 제약](frontend-bamboo-api.md)을 따른 배포가 필요합니다.
6. **외부 SSO 보장 범위:** 비밀번호 변경·재설정 후 다른 기기 세션 폐기, 인증번호 일회성 여부는 이 저장소만으로 검증할 수 없습니다. 이 문서는 Festa에서 확인되는 쿠키 제거와 재로그인 흐름만 보장합니다.

## 문서 갱신 기준

API를 바꿀 때 컨트롤러의 경로·메서드·성공 코드, DTO의 필수값·길이·enum, 서비스의 권한·시간·중복·null 처리를 함께 확인합니다. 파일 파트와 페이지 응답도 도메인마다 다릅니다. 새 DB 테이블에 사용자 UUID나 표시 이름을 저장한다면 탈퇴 처리 범위까지 대조합니다.

OpenAPI 검증 명령:

```powershell
.\gradlew.bat test --tests org.syu_likelion.Festa_2026.config.OpenApiDocumentationIntegrationTests
```

Swagger 타입만으로 nullable, 선택 인증, HTML 오류 처리, 외부 SSO의 내부 정책을 추정하지 않습니다. 현행 계약은 연결된 도메인 문서에 기록하고, 미구현 개선안은 현재 동작과 분리해 둡니다.
