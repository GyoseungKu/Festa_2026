# 관리자 UI 점검 및 수정

2026-09-11 관리자 UI 점검 기록입니다. 2026-09-13에 파일 경로와 레이아웃 설명을 현재 코드에 맞게 갱신했습니다. 현재 공통 구조는 [관리자 디자인 문서](admin-design.md)를 참고합니다.

## 적용 내용

- `/images/festa.png`를 로그인과 사이드바에 표시합니다. 원본 비율과 대체 텍스트를 유지합니다.
- 공통 계정 정보와 로그아웃 POST는 `admin/fragments/sidebar.html`에서 제공합니다. 별도 `admin/fragments/header.html`은 사용하지 않습니다.
- 기본 컴포넌트 CSS 위에 중첩되던 과거 포스터 테마를 제거했습니다. 현재 관리자 색상은 `admin-console.css`에서 관리합니다.
- 대시보드의 학생회비 카드 구조와 좁은 화면의 카드 열 수를 수정했습니다.
- 모바일 로그인에서도 브랜드를 표시합니다. 800px 이하에서는 사이드바를 계정 정보와 로그아웃을 포함한 상단 메뉴로 전환합니다.
- 투표 질문·선택지·미디어 입력, 관리자 선택 목록, 일반 폼의 최소 너비를 조정했습니다. 숨긴 요소는 공통 display 규칙에 의해 다시 나타나지 않습니다.
- 파일 선택 버튼의 투명 입력 영역과 키보드 포커스를 수정했습니다. 투표 집계 막대의 잘못된 인라인 width 표현식을 수정했습니다.
- 테이블 머리글, 본문 바로가기, 폼의 접근 가능한 이름, 성공·오류 알림 역할을 보완했습니다.
- 표 가로 스크롤, 긴 문자열 줄바꿈, 버튼 줄바꿈, 중복 고정 액션 바와 상태 배지 대비를 정리했습니다.

## 검증 범위

추가 간격 점검: 본문 하단 여백을 데스크톱 64px·모바일 40px로 확보하고 본문과 푸터 사이에 각각 24px·20px 간격을 두었습니다. 로그인 푸터와 푸터 내부 문단, 독립 섹션 사이에도 여백을 지정했습니다. 그리드 폼 안의 중복 마진은 제거하고 학생회비 검색 폼·목록 행·페이지 이동 버튼의 간격을 보완했습니다.

당시 점검은 기존 관리자 페이지·기능 테스트와 HTML 소스의 중복 속성·ID 및 중첩 폼 확인을 기준으로 했습니다. 실제 브라우저 스크린샷, 모바일 실측 레이아웃과 카메라·파일 선택 상호작용 검증은 포함하지 않았습니다. 이 기록은 2026-09-14 API 문서 검토에서 새로 수행한 브라우저 검증 결과가 아닙니다.
